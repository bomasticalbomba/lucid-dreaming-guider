# Lucid Dreaming — A Practical Guide

A single-page bilingual (English / العربية) guide to lucid dreaming, built with plain HTML, Tailwind CSS via CDN, and Vanilla JavaScript. No build step, no framework, no server code.

## Features

- Instant English / Arabic toggle with RTL support and Arabic font (Cairo)
- Dreamy dark theme with animated starfield and ambient gradients
- Fully responsive (mobile & desktop)
- Sections on: what lucid dreaming is, dream recall, persistent realities, advanced control & the Effort Paradox, staying longer in dreams, techniques, what to avoid, and curated resources
- Scroll-reveal animations and smooth anchor navigation
- Zero dependencies at runtime — everything loads from CDNs

## Run Locally

Just open `index.html` in any modern browser. That's it.
